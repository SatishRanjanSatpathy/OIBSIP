# OIBSIP : DATA SCIENCE INTERNSHIP

## TASK 2 : SALES PREDICTION USING PYTHON

### Introduction

This project IS to predict product sales based on advertising expenditures on TV, Radio and Newspaper platforms. The Linear Regression model is used to analyze the relationship between advertising budgets and sales.

### About the Dataset

The dataset contains the following columns:

* TV
* Radio
* Newspaper
* Sales

### Python Modules Used

* Pandas
* Matplotlib
* Scikit-learn

### Workflow

1. Loaded the dataset using Pandas.
2. Selected advertising columns as features and sales as the target variable.
3. Split the dataset into training and testing sets.
4. Trained the Linear Regression model.
5. Predicted sales values for the test data.
6. Evaluated the model using the R² Score.
7. Visualized actual and predicted sales using a scatter plot.

### Machine Learning Algorithm

* Linear Regression algorithm is used because the target variable, Sales is a continuous numerical value.


### Model Performance

The model performance was evaluated using the R² Score, which indicates how well the model explains the variation in sales data.

### Conclusion

The Linear Regression model successfully predicts sales based on advertising expenditure. The obtained R² Score shows that the model fits the dataset effectively.
