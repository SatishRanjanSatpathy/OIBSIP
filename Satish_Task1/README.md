# OIBSIP : DATA SCIENCE INTERNSHIP
## TASK1 : IRIS FLOWER CLASSIFICATION

### Introduction

This project is based on the Iris Flower dataset and uses Machine Learning to classify different species of iris flowers. The model predicts the flower species using sepal length, sepal width, petal length and petal width.

### About the Dataset

The Iris dataset contains three different species of flowers:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

The dataset contains a total of 150 flower samples along with their sepal length, sepal width, petal length and petal width measurements. Based on these features, the model predicts the species of the flower.

### Python Modules Used

- Pandas
- Matplotlib
- Scikit-learn

### Workflow

1. Load the Iris dataset using Pandas.
2. Explore the dataset and check its structure and species distribution. 
3. Select important features such as sepal length, sepal width, petal length and petal width.
4. Split the dataset into training and testing data.
5. Create the Random Forest classifier model.
6. Train the Random Forest Classifier model.
7. Predict the flower species using the trained model.
8. Evaluate the model accuracy.
9. Visualize the dataset for better understanding.

### Machine Learning Model

The algorithm used in making this project is Random Forest Classifier because it provides good accuracy and works well for classification problems.

### Output

The model successfully predicts the species of iris flowers based on the values entered by the user.
